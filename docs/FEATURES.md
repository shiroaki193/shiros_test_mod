# Mob Arms Race — 已完成功能

苦力怕學會了迫擊炮，村莊也組織起防空：雪傀儡會攔截炮彈，鐵傀儡會把貓丟向苦力怕。

- 版本：Minecraft 26.1 / NeoForge 26.1.0.19-beta
- 設計與開發細節請見 [DESIGN.md](DESIGN.md)

---

## 進攻方：苦力怕

### 迫擊炮苦力怕

新的敵對生物，可以用 **迫擊炮苦力怕生怪蛋**（創造模式「生怪蛋」分頁）生成。

- 會攻擊 **128 格內**的村民、鐵傀儡和玩家（依此優先順序），不需要看得到目標。
- 目標在 **10 到 120 格**之間時，會停下腳步、像點燃的苦力怕一樣閃爍蓄力，接著朝目標**齊射 4 發**炮彈。每發之間相隔 4 tick，落點會隨機偏移約 1.5 格。
- 炮彈打完後就變回普通苦力怕，會走過去自爆。
- **附近 6 格內有貓或豹貓時不會開火**；正在齊射時有貓靠近也會立刻中斷。

### 苦力怕炮彈

- 外觀是一顆飛行中的苦力怕頭，拖著發光的紅色尾跡，晚上也看得很清楚。
- 以 60° 高拋發射。120 格的射程大約飛 5.4 秒，最高點約 70 格，落下時幾乎是垂直俯衝（約 74°）。
- 撞到方塊或生物時爆炸（威力 2，普通苦力怕是 3），會不會破壞方塊依 `mob_griefing` 遊戲規則決定。

### 手持苦力怕炮彈（玩家用）

創造模式「戰鬥」分頁的 **苦力怕炮彈** 道具，最多疊 16 個。

- **看著地面上想打的點**，按右鍵發射，炮彈會以高拋落在那個點上，最遠 120 格。每發冷卻 1 秒。
- 拿在手上時會顯示**落點準星**：
  - 黃色虛線畫出炮彈的飛行弧線，落點有一圈黃色標記。
  - 動作列顯示距離和飛行時間，例如「Impact: 31 blocks, 2.6 s」。
  - 弧線中途會撞到屋頂或山壁時，顯示「Arc blocked before the target!」，標記會畫在實際會撞到的位置。
  - 看的地方超過 120 格時，顯示「No target within 120 blocks」，這時無法發射。

### 抓起並投擲苦力怕

- **空手右鍵點苦力怕**，會把它收進手中，變成「手持苦力怕」物品。任何苦力怕都可以，包括迫擊炮苦力怕。
- **拿著它按右鍵**，就沿視線方向把苦力怕丟出去，撞到地面、牆壁或生物時爆炸（普通苦力怕威力 3，閃電苦力怕威力 6）。
- 物品會保存苦力怕的完整狀態，迫擊炮苦力怕丟出去時仍保有原本的剩餘彈藥。玩家死亡時會掉落這個物品，苦力怕不會消失。

## 防守方：村莊

### 雪傀儡近防炮

**所有雪傀儡**（包括原版生成和玩家做的）都會自動攔截苦力怕炮彈：

- 偵測 48 格內的炮彈。只有當炮彈**正在下降、距離 28 格內、而且預測會落在自己 24 格內**時才開火，落點在別處的炮彈不會浪費火力。
- 以每秒 10 發的速度射出高速直線雪球（留下白色曳光），並自動計算提前量。
- 擊落時炮彈在空中爆成白色煙火，不會傷害任何東西。
- 攔截率很高，但不是 100%：2 隻雪傀儡對上一輪 4 發齊射，約 90% 的炮彈會被攔下。

### 鐵傀儡擲貓

**所有鐵傀儡**都會拿貓對付苦力怕：

- 發現 24 格內有苦力怕，而且 16 格內有貓時，鐵傀儡會走過去把貓舉過頭頂，再把牠丟到苦力怕旁邊。
- 貓在空中會拖著白色雲霧；落地時會哈氣。貓本來就不會受到摔落傷害。
- 貓落地後，**6 格內的苦力怕**會停止引爆、失去目標並被推開，迫擊炮苦力怕也會停止開火。
- 預設**不會丟有主人的貓**。
- 丟完之後有 3 秒冷卻。

## 設定檔

所有平衡數值都在 `config/mobarmsrace-common.toml`，也可以在遊戲的「模組」畫面中點選本 Mod 的「設定」修改。

| 分類 | 設定 | 預設值 | 說明 |
|---|---|---|---|
| 迫擊炮苦力怕 | `ammo` | 4 | 攜帶的炮彈數 |
| | `maxRange` / `minRange` | 120 / 10 | 射程（格） |
| | `salvoInterval` | 4 | 齊射間隔（tick） |
| | `scatter` | 1.5 | 落點隨機偏移（格） |
| | `shellExplosionPower` | 2.0 | 炮彈爆炸威力 |
| 雪傀儡近防炮 | `enabled` | true | 是否啟用 |
| | `detectRange` / `engageRange` / `protectRadius` | 48 / 28 / 24 | 偵測、開火、保護範圍（格） |
| | `fireInterval` | 2 | 射擊間隔（tick） |
| | `bulletSpeed` | 4.0 | 雪球速度（格/tick） |
| | `spreadDegrees` | 18 | 散佈角度。16° 攔截率約 96%、18° 約 90%、20° 約 67% |
| 鐵傀儡擲貓 | `enabled` | true | 是否啟用 |
| | `throwRange` / `catSearchRange` | 24 / 16 | 擲貓距離、找貓範圍（格） |
| | `scareRadius` | 6 | 貓嚇阻苦力怕的範圍（格） |
| | `throwTamedCats` | false | 是否也會丟有主人的貓 |

## 目前的限制

- 迫擊炮苦力怕不會自然生成，只能用生怪蛋或指令召喚。
- 苦力怕炮彈還沒有生存模式的合成配方。
- 貓飛行時還沒有「超人姿勢」動畫。
- 炮彈只有在區塊有載入（位於玩家的模擬距離內）時才會移動。
