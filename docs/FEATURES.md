# Mob Arms Race — 已完成功能

苦力怕學會了迫擊炮，村莊也組織起防空：雪傀儡會攔截炮彈，鐵傀儡會把貓丟向苦力怕。

- 版本：Minecraft 26.1.2 / NeoForge 26.1.2.109 或更新
- 設計與開發細節請見 [DESIGN.md](DESIGN.md)

---

## 進攻方：苦力怕

### 迫擊炮苦力怕

新的敵對生物。**自然生成的苦力怕有 40% 會變成迫擊炮苦力怕**，也可以用 **迫擊炮苦力怕生怪蛋**（創造模式「生怪蛋」分頁）生成。

- 會主動攻擊 **128 格內**的村民、鐵傀儡和雪傀儡（打最近的一個），其次才是玩家；不需要看得到目標。
- 目標在 **10 到 120 格**之間時，會停下腳步、像點燃的苦力怕一樣閃爍蓄力，接著朝目標**齊射 4 發**炮彈。每發之間相隔 4 tick，落點會隨機偏移約 1.5 格。
- 一輪打完後會**原地裝填 8 秒**，再蓄力齊射下一輪，只要目標還在射程內就會持續開火。
  - 目標比 10 格還近時，它會像普通苦力怕一樣走過去自爆。
  - 把 `reloadTicks` 設成 0 可以關掉裝填，改成打完一輪就變回普通苦力怕。
- **壽命有限**：一生最多發射 **10 發**炮彈（第 3 輪只打 2 發），第 10 發射出後就冒出黑煙燃盡死亡。發射數會存檔，收進手中再丟出去也會保留。
- **附近 6 格內有貓或豹貓時不會開火**；正在齊射時有貓靠近也會立刻中斷。
- 用生怪蛋或指令放置的迫擊炮苦力怕，不會在遠離玩家時自然消失，可以放在遠處的山丘上當固定炮台。自然生成的則會像普通苦力怕一樣消失，免得世界裡越積越多。

### 苦力怕炮彈

- 外觀是一顆飛行中的苦力怕頭，拖著發光的紅色尾跡，晚上也看得很清楚；遠在 100 格外也能看到完整的弧線。
- 以 60° 高拋發射。120 格的射程大約飛 5.4 秒，最高點約 70 格，落下時幾乎是垂直俯衝（約 74°）。
- 同時具備兩種引信（爆炸威力 2，普通苦力怕是 3；會不會破壞方塊依 `mob_griefing` 遊戲規則決定）：
  - **碰炸**：撞到方塊或生物時爆炸。
  - **近炸**：下降途中接近村民、鐵傀儡、雪傀儡或玩家 3 格內就在空中引爆，通常在目標頭部高度爆炸。
- 被雪傀儡擊落時，有兩種結果：
  - **彈頭爆炸**：在高空攔截不會傷到地面，但攔截得太晚、就在雪傀儡附近時，雪傀儡也會被炸傷。
  - **分裂成小炸彈**（機率 50%，只在離地 20 格以上被擊落時）：炮彈碎成 2 到 5 顆小炸彈，保留大部分速度並向四周散開，落地或撞到生物時爆炸。每顆的爆炸威力是 1（炮彈是 2），傷害範圍 2 格（炮彈 4 格）。實測同樣落在村民 1.5 格外，炮彈造成 15.2 點傷害、小炸彈 3.2 點；小炸彈直接命中 6.4 點；落在 3 格外沒有傷害。小炸彈不會再分裂。
  - 雪傀儡**只有在沒有整顆炮彈來襲時**才會打小炸彈，而且先打預計落在自己最近的那顆。被擊落的小炸彈在空中爆開。
  - 20 格以下被擊落的炮彈不會分裂：那通常是瞄準雪傀儡本身、最後才被攔下的炮彈，碎片沒有空間散開，會直接落在雪傀儡身上。

### 手持苦力怕炮彈（玩家用）

創造模式「戰鬥」分頁的 **苦力怕炮彈** 道具，最多疊 16 個。

- **看著地面上想打的點**，按右鍵發射，炮彈會以高拋落在那個點上，最遠 120 格。每發冷卻 1 秒。
- 拿在手上時會顯示**落點準星**：
  - 黃色虛線畫出炮彈的飛行弧線，落點有一圈黃色標記。
  - 動作列顯示距離和飛行時間，例如「Impact: 31 blocks, 2.6 s」。
  - 弧線中途會撞到屋頂或山壁時，顯示「Arc blocked before the target!」，標記會畫在實際會撞到的位置。
  - 看的地方超過 120 格時，顯示「No target within 120 blocks」，這時無法發射。

### 抓起並投擲苦力怕

- **空手右鍵點苦力怕**，會把它收進手中，變成「手持苦力怕」物品。任何苦力怕都可以，包括迫擊炮苦力怕。
- **拿著它按右鍵**，就沿視線方向把苦力怕丟出去，撞到地面、牆壁或生物時爆炸（普通苦力怕威力 3，閃電苦力怕威力 6）。
- 物品會保存苦力怕的完整狀態，迫擊炮苦力怕丟出去時仍保有原本的剩餘彈藥。玩家死亡時會掉落這個物品，苦力怕不會消失。

## 防守方：村莊

### 雪傀儡近防炮

**所有雪傀儡**（包括原版生成和玩家做的）都會自動攔截苦力怕炮彈：

- 只有當炮彈**預計 4 秒內落地、距離 96 格內、而且預測會落在自己 24 格內**時才開火，落點在別處的炮彈不會浪費火力。炮彈常常還在上升段就開始迎擊。
- **射控收斂**：剛鎖定一發炮彈時散佈是 15°，持續追蹤 1.5 秒後逐漸收斂到 5°。所以曳光會先在炮彈周圍亂飛，再慢慢咬上去。
- **停火窗口**：炮彈離落地不到 2.5 秒（50 tick）時就停止對它開火，已經在空中的雪球仍然可能命中。攔截因此集中在高空，也會有炮彈突破。
- **最後自衛**：預測落點在雪傀儡自己 4 格內（炮彈爆炸的傷害範圍）的炮彈不受停火窗口限制，會一直打到最後。所以瞄準雪傀儡的炮彈幾乎都會被擋下，站在雪傀儡身邊的村民也比較安全。
- 攔截通常發生在離地 50 到 70 格的高空，爆散不會落在村莊頭上。從 90 格外山丘射向村民的炮彈，約一半在還在雪傀儡上方 60 格以上時就被擊落（同時來襲的炮彈太多時會比較低）。
- 雪傀儡**不怕天氣**：淋雨、泡水、待在沙漠或熱帶草原等炎熱生態域都不會受傷（原版每秒扣 2 點，很快就會融化）。真正著火、岩漿、攻擊和爆炸仍然會造成傷害。
- 雪傀儡會**守在崗位上**：第一次出現的位置就是崗位，之後只在 6 格內活動，開火時也會停下腳步。所以要把雪傀儡放在想保護的東西旁邊。
- 以每秒 10 發的速度射出高速直線雪球（留下白色曳光），並自動計算提前量。
- 開火前會先確認射擊路線沒有被屋頂、樹木或地形擋住；最近的炮彈被擋住時，會改打其他路線暢通的炮彈。
- **沒有炮彈來襲時，會用同樣的連射攻擊 24 格內的敵對生物**（殭屍、骷髏、苦力怕等），取代原版丟雪球的攻擊。每發 2 點傷害，而且不會把目標擊退出射程；單隻雪傀儡約 5 到 10 秒可以打死一隻殭屍。雪球會穿過村民、傀儡和玩家，不會誤傷。炮彈來襲時一律優先攔截炮彈。
- 擊落時炮彈在空中爆成白色煙火，同時彈頭爆炸。一般攔截高度（離地 20 到 30 格）不會傷到任何東西，太晚攔截則可能炸傷雪傀儡自己。
- **攔截率約 70% 到 85%**（測試結果）：
  - 村莊屋頂的 2 隻雪傀儡，對 90 格外 40 格高山丘射向村民的齊射：約 70% 到 77%，其中約一半在雪傀儡上方 60 格以上就被擊落。瞄準雪傀儡本身的炮彈幾乎全部攔下（最後自衛）。
  - 3 隻雪傀儡對山丘上的迫擊炮陣地（60 秒）：1 門約 85%，4 門約 70% 到 79%，8 門約 64%，雪傀儡和村民全部存活。
  - 射程短的炮彈（約 40 格）飛行時間短，能開火的時間較少：1 隻雪傀儡站在目標 8 格外時約 50%。
  - 目標就在雪傀儡身邊（4 格內）時接近 100%。
- 會突破的情況：炮彈落在所有雪傀儡的 24 格範圍之外（例如村民走到村莊邊緣）、只有 1 隻雪傀儡，或同時面對多隻迫擊炮苦力怕。想保護整個村莊，要把雪傀儡分散放在各處。

### 鐵傀儡擲貓

**所有鐵傀儡**都會拿貓對付苦力怕：

- 發現 24 格內有苦力怕，而且 16 格內有貓時，鐵傀儡會走過去把貓舉過頭頂，再把牠丟到苦力怕旁邊。
- 貓在空中會拖著白色雲霧；落地時會哈氣。貓本來就不會受到摔落傷害。
- 貓落地後，**6 格內的苦力怕**會停止引爆、失去目標並被推開，迫擊炮苦力怕也會停止開火。
- 預設**不會丟有主人的貓**。
- 丟完之後有 3 秒冷卻。

## 設定檔

所有平衡數值都在 `config/mobarmsrace-common.toml`，也可以在遊戲的「模組」畫面中點選本 Mod 的「設定」修改。

| 分類 | 設定 | 預設值 | 說明 |
|---|---|---|---|
| 迫擊炮苦力怕 | `naturalShare` | 0.4 | 自然生成的苦力怕變成迫擊炮苦力怕的比例（0 到 1） |
| | `ammo` | 4 | 每輪齊射的炮彈數 |
| | `reloadTicks` | 160 | 每輪之間的裝填時間（tick，160 = 8 秒）；0 = 不裝填，打完變回普通苦力怕 |
| | `shellLimit` | 10 | 一生最多發射的炮彈數，打完就死亡；0 = 無上限 |
| | `maxRange` / `minRange` | 120 / 10 | 射程（格） |
| | `salvoInterval` | 4 | 齊射間隔（tick） |
| | `scatter` | 1.5 | 落點隨機偏移（格） |
| | `shellExplosionPower` | 2.0 | 炮彈爆炸威力（傷害範圍約為威力的 2 倍格數） |
| | `proximityFuze` | 3.0 | 近炸引信距離（格，量到目標腳底）；0 = 只有碰炸 |
| | `fragmentChance` | 0.5 | 被擊落時分裂成小炸彈的機率（0 到 1）；0 = 一律彈頭爆炸 |
| | `fragmentsMin` / `fragmentsMax` | 2 / 5 | 小炸彈數量範圍 |
| | `fragmentPower` | 1.0 | 每顆小炸彈的爆炸威力（傷害範圍約為威力的 2 倍格數） |
| 雪傀儡近防炮 | `enabled` | true | 是否啟用 |
| | `postRadius` | 6 | 崗位範圍（格）；0 = 像原版一樣自由走動 |
| | `gunRange` / `protectRadius` | 96 / 24 | 射程、保護範圍（格） |
| | `selfDefenseRadius` | 4 | 落點在自己這麼近的炮彈，無視停火窗口打到最後（格）；0 = 關閉 |
| | `golemHealth` | 4 | 雪傀儡最大生命（原版 4） |
| | `weatherproof` | true | 雪傀儡不會因雨水、水、炎熱生態域受傷 |
| | `engageTicks` | 80 | 炮彈預計在這麼多 tick 內落地才開火（80 = 4 秒） |
| | `ceaseFireTicks` | 50 | 炮彈離落地不到這麼多 tick 就停火（太近、太快，追不上）；0 = 不停火 |
| | `antiMobRange` | 24 | 對敵對生物開火的距離（格）；0 = 只打炮彈 |
| | `antiMobDamage` | 2.0 | 每發雪球對敵對生物的傷害（殭屍有 20 點生命） |
| | `fireInterval` | 2 | 射擊間隔（tick） |
| | `bulletSpeed` | 4.0 | 雪球速度（格/tick） |
| | `aimErrorStart` / `aimErrorSettled` | 15 / 5 | 剛鎖定時的散佈、追蹤收斂後的散佈（度） |
| | `trackingTicks` | 30 | 從 `aimErrorStart` 收斂到 `aimErrorSettled` 所需的追蹤時間（tick） |
| 鐵傀儡擲貓 | `enabled` | true | 是否啟用 |
| | `throwRange` / `catSearchRange` | 24 / 16 | 擲貓距離、找貓範圍（格） |
| | `scareRadius` | 6 | 貓嚇阻苦力怕的範圍（格） |
| | `throwTamedCats` | false | 是否也會丟有主人的貓 |

### 從舊版更新

NeoForge 更新 mod 時，設定檔裡已經寫下的數值不會跟著新預設值改變。1.0.1 起：
- 移除了 `detectRange`（改由 `gunRange` 決定）。
- `spreadDegrees` 改名為 `aimErrorSettled`，舊檔案裡的 10° 或 18° 會被丟掉，改用新預設值。

1.0.3 起，設定檔多了一個內部項目 `balanceVersion`。載入較舊的設定檔時，雪傀儡射控的 5 個數值（`engageTicks`、`ceaseFireTicks`、`aimErrorStart`、`aimErrorSettled`、`trackingTicks`）會自動更新成新的預設值一次，日誌會記錄這件事。之後手動修改的數值會保留。

如果曾經手動改過其他數值，想恢復預設可以直接刪掉 `config/mobarmsrace-common.toml`。

## 目前的限制

- 苦力怕炮彈還沒有生存模式的合成配方。
- 貓飛行時還沒有「超人姿勢」動畫。
- 炮彈只有在區塊有載入（位於玩家的模擬距離內）時才會移動。
